Write Your First Jenkins Pipeline

Jenkins pipelines are usually written using a Jenkinsfile. Each stage represents a step in your automation process.

This example demonstrates how Jenkins can clone a repository, build an application and deploy it automatically.

Understand Pipeline Stages
Jenkinsfile Declarative Pipeline 
pipeline {

    agent any

    stages {

        stage('Clone Repository') {
            steps {
                git
                'https://github.com/user/project.git'
            }
        }

        stage('Build') {
            steps {
                sh 'npm install'
            }
        }

        stage('Deploy') {
            steps {
                sh 'cp -r * /var/www/html/'
            }
        }

    }
}
